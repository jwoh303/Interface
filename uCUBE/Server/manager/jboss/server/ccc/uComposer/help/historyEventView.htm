시간별 정보조회

인터페이스 별 일자기준 시간 별 처리건수를 조회하여 시간대별 처리건수, 일 Total 처리건수를 분석

 

 

가. 시간별 정보조회

인터페이스ID

u-CUBE 를 통한 인터페이스 관리항목

트랜잭션코드

업무 팀 정의 항목

날짜

조회하고자 하는 날짜 (data 발생 날짜)

송수신 구분

해당 인터페이스의 송신,수신 구분

시스템

해당 인터페이스의 시스템 이름

합계

인터페이스의 총 발생량 (송신,수신 건수)

시간

인터페이스의 시간별 발생 건수

가. 시간별 정보 조회

 “조회” 버튼을 눌러 시간별 인터페이스 처리건수를 조회한다.

 인터페이스 ID 또는 트랜잭션 코드를 입력하고 “조회” 버튼을 눌러 인터페이스 처리건수를 조회한다.

 조회하고자 하는 날짜를 달력 ICON 을 눌러 선택한 후 “조회” 버튼을 눌러 인터페이스 처리건수를 조회한다.
