피피아이평화 주식회사
택배 도착지 영업소 변경 요청 안내
피피아이평화 주식회사의 택배 납품 시 요청 사항 공지드립니다.
(직접납품 및 TR 거래 제외)

하기 택배사 이용 시 지정 영업소로 발송될 수 있도록
안내드리오니 업무에 참고 부탁드립니다.

택배 도착지 영업소 변경 요청을 드리는 것은,
택배 발송 하실 때 피피아이평화 주식회사로 물품이 최종 도착하되
중간 도착지 영업소를 변경 요청 드린것입니다.
화물 거래가 아닌 택배 거래는 유지한채 도착영업소만 변경하는 것이오니
물품이 영업소를 종점으로 도착하는 일이 없도록 주의해주시기 바랍니다.

▶ 도착지 영업소
- 경동택배 : 화성장안석포 392
- 대신화물 : 화성석포지점

▶ 사유
타 택배사 및 영업소의 경우 입고시 공장별로 내려달라는 요청이 잘 이루어지지 않는다고 하시어 피피아이평화 주식회사 기존 거래 지점으로 받고자 합니다.
