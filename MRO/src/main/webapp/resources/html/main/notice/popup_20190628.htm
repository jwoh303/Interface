크린팩토메이션(주) 제품 납품 시 주의사항 안내

수신 : 크린팩토메이션(주) 거래 협력사 대표님

귀사의 일익 번창을 기원드리며, 크린팩토메이션(주) 제품 납품 시 주의사항 안내를 드리오니, 반드시 이점 유의하시어 납품진행 부탁드립니다.

1. 납품 시 주의 사항
- 납품 시 거래명세서 3부(고객사 담당자/경비실/협력사용)와 현품표 부착 필수
- 현품표는 반드시 발주번호(PO No.)/프로젝트명/Unit 별 별도 부착 필요
  (동일물품이라도 발주번호/프로젝트명/Unit이 다를 경우 현품표 별도 부착 필요)
- 현품표 오부착 시 고객사 물품 수령 거부 계획
  (분류 기준에 맞게 현품표 부착 후 한박스에 담아 배송하는것은 가능함)

2. 정확한 납품예정일 정보 기입 부탁드립니다.
