코웨이 명함신청 시
★ 표준양식 사용 및 암호화 미해제 권장 안내 ★
코웨이 명함신청 시 유의사항을 다음과 같이 안내드리오니 반드시 숙지하시어 사이트 이용에 차질 없으시기 바랍니다.

1. 3월 11일 이후 코웨이 명함 표준양식이 아닌, 기존에 사용하시던 양식 또는 별도의 양식으로 작성된 제작파일은 모두 인정될 수 없으며 발주 삭제 대상에 포함됩니다. 표준양식은 장바구니에 명함 품목을 담아주신 뒤 우측에 엑셀다운 메뉴를 이용해주시면 바로 다운로드 가능하오니 업무에 참고 부탁드립니다.

2. 1번과 마찬가지로, 작성된 모든 양식은 반드시 암호화 해제된 상태여야만 제작 진행 가능하며 암호화 해제되지 않은 파일을 첨부해주실 경우 발주 삭제 대상에 포함됩니다. 발주 삭제 대상건은 코웨이 메일로 발주자분들께 사전안내드린 뒤 취소 처리하고 있으니 이 점 참고 부탁드리며 암호화 해제 방법은 정보전략팀에 문의 부탁드리겠습니다.

위 내용으로 명함 신청 관련 공지사항 안내드리오니 오발주로 인해 업무에 불편이 없으시도록 숙지 부탁드립니다.
