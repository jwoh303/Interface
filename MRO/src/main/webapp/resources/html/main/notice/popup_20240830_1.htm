결재 관련 안내의 건
1) 주문/발주 상품구매의 경우 결재선은 각 소속부서의 팀장에게 결재요청 하셔야 합니다.
결재자 이름 검색 시 조회가 안되는 경우 KeP 사이트 내 가입이 안되어있는 사용자로
KeP 사이트 내 사용자 가입 (일반사용자) 후 총무팀 최경웅 책임에게 사용자 승인 요청 부탁드립니다.

2) 신규견적의뢰 의 경우 결재선은 총무팀 최경웅 책임으로 지정하여 결재요청 하셔야 합니다.
신규품목 견적 관련 승인 및 단가합의는 총무팀 최경웅 책임에게 문의 부탁드립니다.
기타 사용문의 관련 해서는 사이트 내 오른쪽 운영 또는 영업담당자에게 연락 주세요.
