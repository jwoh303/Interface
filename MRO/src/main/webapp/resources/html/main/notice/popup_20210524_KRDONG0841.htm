★ 결재자 지정 및 변경 방법 ★

전체메뉴 > 상신함 > [결재선관리] 버튼 >
행 추가(혹은 기존 결재선) > [결재자] 버튼 클릭 >
하단 결재자 지정 칸에서 담당자 조회 및 저장

KEP 결재자 지정 칸에서 담당자가 조회되지 않는 경우,
자사 사이트 회원가입 여부 확인 후 미가입 시 아래와 같이 진행 바랍니다.


★ 회원가입 방법 ★

1. http://www.koreab2b.com/ 사이트 내 우측 상단 [회원가입] 클릭
2. 이용약관 동의 후 하단 [회원사명 검색] 클릭
3. 고객사 코드 동원팜스주식회사(KRDONG0841) 선택
4. [사용자 등록하기]로 회원가입 진행
5. 가입 완료 이후 KEP 담당자에게 ID 송부
6. KEP 담당자가 가입 승인 후 정상적으로 이용 가능
