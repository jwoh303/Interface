1. 거래명세서 동봉 必
공장에 물품 입고 시 거래명세서가 누락되는 경우가 종종 발생하여 택배 발송 시 거래명세서 출력 후 서류 봉투에 동봉하시어 택배 박스 겉면에 부착 요청드립니다.

2. 거래명세서 유형 구별 요청
납품 시 고객사 출품용 거래명세서와 물류창고용 거래명세서를 구별하시어 동봉 부탁드립니다. 물류창고용 거래명세서는 납품장소가 코리아e플랫폼 물류센터로 지정되어있으며 공장 주소/수령인의 정보가 없습니다. 공장에 바로 납품하시는 경우(택배,직납) 필히 확인하시어 전달 부탁드립니다.
