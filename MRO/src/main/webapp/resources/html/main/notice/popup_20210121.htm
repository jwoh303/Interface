롯데제과 평택공장 납품 시 거래명세서 동봉 요청사항
1. 거래명세서 동봉 必
공장에 물품 입고 시 거래명세서가 누락되는 경우가 많이 발생하여 택배 발송 시 거래명세서 출력 후
서류 봉투에 동봉하시어 택배 박스 겉면에 부착 요청드립니다.
-> 거래명세서가 누락되는 경우 담당자가 거래명세서를 KeP를 통해 받은 뒤 물건과 거래명세서를
    경비실로 다시 들고가 도장을 받아야하는 번거로움이 있으며, 업무상의 로스가 심하게 발생하여
    클레임이 폭주하고있습니다. 필히 거래명세서를 챙겨주세요.
    (특히, 발주자 강주연님,송은영님,음대식님 앞으로 배송되는 제품에 거래명세서 누락이 굉장히 많습니다.)

2. 거래명세서 유형 구별 요청
납품 시 고객사 출품용 거래명세서와 물류창고용 거래명세서를 구별하시어 동봉 부탁드립니다.
물류창고용 거래명세서는 납품장소가 코리아e플랫폼 물류센터로 지정되어있으며 공장 주소/수령인의
정보가 없습니다. 공장에 바로 납품하시는 경우(택배,직납) 필히 확인하시어 전달 부탁드립니다.

※ 거래유형 변경 요청 시 코리아e플랫폼 담당자에게 연락 바랍니다.
※ 거래명세서 미발송 or 오발송 시 물품/발주자 정보 확인불가, 분실위험 등의 사유로 마감 지연,
이월 될 수 있으니 반드시 협조 부탁드립니다.
