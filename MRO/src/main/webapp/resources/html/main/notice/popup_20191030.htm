롯데알미늄에서 사전 담당자와 협의 되지 않은 택배 발송건에 대해서는 향후 반송 처리될 예정입니다. 택배배송의 경우 택배사에서 경비실로 물품을 두고 가는 경우가 많아 제품 분실 / 택배 박스내 명세서 누락 / 제품 수령 확인이 늦어지는 등의 문제가 발생하여 현장 담당자들의 불만이 높아진 상태입니다.

때문에 11월 1일부터는 직접 납품이 불가능한 제품의 경우 당사 담당자에게 납품처 변경 요청을 하여 안산물류센터(TR)로 납품하시기 바랍니다. 다만, 안산물류센터(TR) 이용시 당사가 직접 배송 및 검수를 대행하기 때문에 물류비를 징수하오니, 참고하시기 바랍니다.
