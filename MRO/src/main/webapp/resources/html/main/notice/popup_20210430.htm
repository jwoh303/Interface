KeP 사무용품 MALL 이용 관련 변동사항 공지의 건 (2021/5/1부 시행)
1. 사무용품 구매는 KeP Mall 예산조회에 등록된 예산을 기준으로 통제됩니다.

2. 사무용품 구매 예산이 부족할 경우 이월/전용을 통한 증액 후 구매해야 되며,
   예산 이월/전용 절차는 기존과 동일합니다.

* 주의 : 당월 사무용품 예산은 타월 또는 타계정으로 이월/전용 불가합니다.
불가 사유 예시) 4월 사무용품 예산 10만원(ERP, KeP몰) → 4월 사무용품 9만원 구매(KeP몰) → 4월 사무용품 중 2만원을 5월로 이월(ERP) → 사무용품 예산 1만원 부족 발생 (8만원 - 9만원 = -1만원) → 4월 말일 마감 불가


3. 사무용품 예산 관리를 위하여 매월 25일 ~ 말일동안은 사무용품 주문이 불가합니다.

4. 기타 문의사항은 경영관리팀 예산 담당자에게 문의하시기 바랍니다.
