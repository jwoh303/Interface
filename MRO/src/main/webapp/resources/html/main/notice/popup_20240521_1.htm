24년도 MRO 사이트 신규 상품 검색/구매 시 사용자 편의성 개선의 일환으로
KEP 전략협력사(크레텍책임)의 전자카탈로그 추가 도입
크레텍 카탈로그의 다양한 상품 조회와 상세정보(이미지포함) 제공을 통한 상품 구매 시 활용

개발
사항		 최초 사용자 로그인 후 상품검색란 오른쪽 '크레텍 카탈로그' 접속 배너 개발
( 배너 클릭 시 '크레텍 전자카탈로그' 접속 )
사용
방법		 1. 전자카탈로그 접속 후 필요 물품 조회(품명, 규격, 모델로 조회)
2. 제품 이미지, 상세규격 확인 후 KEP 사이트 내 신규견적의뢰 요청
3. 신규상품 요청 시 규격정보 + 크레텍 상품코드 '000-0000' 입력 후 견적 요청 진행
※ 신규상품 중 MRO사이트 내 미등록 상품의 경우 KEP 입찰비딩 후 품목코드 등록(GFS 구매팀 합의 必)
