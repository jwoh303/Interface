[필독] 사무용품몰 이용 관련 안내
예산계정 사용 - 작업소모품비 계정은 인쇄물[프린테크-양식지/봉투 외] 구입 시에만 사용 가능
   (인쇄물이 아닌 일반 사무용품에 '작업소모품비'를 적용할 경우 반려 처리 됨)
- 사무용품몰은 '기업문화팀' 소관으로, 상신 시 기업문화팀의 결재 必
전결 규정 발주자 → 발주부서 파트장 → 팀장 → 기업문화팀 사무용품 담당자 → 기업문화팀 팀장
(참고) 공장별 사무용품 담당자 - 창녕: 송재호 선임 / 양산: 김예림 사원 / 기타: 홍준우 수석
※ 발주자 부서 내부 결재라인은 상황에 따라 변동될 수 있습니다.
발주프로세스 - 주문상태 확인: 결재 진행 상황 및 발주 여부 확인 필요 (결재완료 시 PO번호가 생성되었는지 확인해야 합니다.)
   결재 완료 후에도 PO 번호가 없는 경우 SAP 예산잔액 먼저 확인 후 KeP 담당자에게 문의.
- 발주자가 SAP 시스템에서 검수 결재 진행
※ 분기 예산 마감 이슈 발생할 경우, 마감일 수일 전 KeP와 반드시 사전 협의 필요
