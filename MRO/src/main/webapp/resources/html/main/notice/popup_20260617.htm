MRO 구매 시스템 사용 불가에 따른 MRO 품목 구매진행 방안
26년 MRO 재계약 진행에 따른 MRO 시스템 작업 기간을 안내드리 오니,
해당 기간 아래와 같이 MRO 구매 진행 바랍니다.
1. MRO 시스템 작업에 따른 MRO 시스템 사용 불가 : 6/29(월) ~ 6/30(화)
(※ 단 KEP 시스템 등록 완료 시점에 따라 일정 변동 가능)
2. MRO 시스템 사용 불가 기간 中 MRO 품목 구매진행
가. 구매 요청자는 아래 양식을 작성하여 각 사업장 업무지원팀/연구지원팀 구매담당자 메일로 전달
나. 각 사업장 업무지원팀/연구지원팀 구매담당자는 사업장 구매 요청건 일괄 수합 후,
     조해주선임/최원철 주임에게 메일 전달
다. 구매요청자는 7/1(수) 이후 MRO 사이트로 구매 요청
사업장 요청부서 요청자 자재코드 자재내역 단위 구매수량 납기요청일 비고
문의 사항 있으시면 구매3팀 김윤집 과장에게 문의 바랍니다.
